# 画面状態とエラー表示

> ステータス: F/S結果反映済み
>
> 最終更新日: 2026-09-21

## 目的

この文書は、初期リリースで各画面が持つ通常、処理中、空、拒否、失敗の状態と、ユーザーが次に選べる操作を定める。文言そのものは日本語・英語の翻訳resourceで管理し、本実装changeで確定する。

## 状態一覧

| 画面 | 状態 | 表示・操作 |
| --- | --- | --- |
| タイトル | 通常 | Start、言語切替、versionを表示する |
| タイトル | 開始確認中 | Startの重複操作を防ぎ、最新版・API・catalogを確認中であることを示す |
| タイトル | 更新が必要 | 制作状態を作らず、再読み込み操作を表示する |
| タイトル | 開始失敗 | 通信失敗を説明し、再試行を表示する。古いcatalogで制作を開始しない |
| テンプレート選択 | 読み込み済み | 公開中templateをサムネイルと名称で表示する |
| テンプレート選択 | 空 | 利用可能なtemplateがないことと、Startから再確認する操作を表示する |
| テンプレート選択 | asset準備中 | 選択したtemplateの線画と全maskを取得・decodeし、別templateの選択を一時的に抑止する |
| テンプレート選択 | asset準備失敗 | 部分resourceを解放し、再試行と一覧へ戻る操作を表示する |
| 制作 | 通常 | 作品、中央固定のエリア選択、三つの塗り方、完成操作を表示する |
| 制作 | 未着色あり | 未着色を区別して表示するが、完成操作を無効化しない |
| 制作 | 戻る確認 | 制作内容を破棄してtemplate選択またはタイトルへ戻るか確認する |
| カメラ | 利用理由の説明 | 初回の権限要求前にカメラが必要な理由と続行・キャンセルを表示する |
| カメラ | 起動中 | stream取得中であることを示し、重複した起動を防ぐ |
| カメラ | ライブ表示 | 作品比較slider、pan、pinch、撮影、カメラ切替、キャンセルを提供する |
| カメラ | 権限拒否 | ブラウザまたは端末設定の確認方法、もう一度試す、写真・単色へ切り替える操作を表示する |
| カメラ | 利用不可 | カメラなし、他アプリ使用中、取得失敗を安全に分類し、再試行と別の塗り方を表示する |
| 写真選択 | OS picker表示 | pickerをOSへ委ねる。キャンセルはエラーにせず制作へ戻る |
| 写真選択 | decode・正規化中 | 選択した画像を標準APIでdecodeし、長辺4096px以下かつ12MP以下へ正規化する |
| 写真選択 | decode失敗 | 形式名だけで断定せず、画像を読み込めなかったこと、選び直す、制作へ戻る操作を表示する |
| 写真調整 | 通常 | 作品比較slider、pan、pinch、反映、キャンセルを提供する。余白と透明部分には初期カラーを表示する |
| 単色調整 | 通常 | 作品全体の一時preview、不透明色用標準color input、反映、キャンセルを表示する。選択した色は反映までArtworkへ確定しない |
| 完成確認 | PNG生成中 | 1080×1080 PNGを生成中であることを示し、重複生成を防ぐ |
| 完成確認 | 生成失敗 | 再試行と制作へ戻る操作を表示する |
| 完成確認 | 通常 | 保存可能な画像、長押し保存案内、共有、共有文コピー、制作へ戻る、もういちど遊ぶを表示する |
| 完成確認 | 共有中 | 同じPNG Blobを使ってOS共有シートを開き、共有操作の重複を防ぐ |
| 完成確認 | 共有キャンセル | エラーを表示せず通常状態へ戻す |
| 完成確認 | File共有非対応・共有失敗 | 長押し保存と、共有文のコピーまたは手動選択へ案内する |
| 完成確認 | Clipboard失敗 | 共有文を選択可能なtextとして表示し、手動コピーを案内する |

## F/Sで確定した表示上の制約

- カメラと写真の編集領域だけに`touch-action: none`相当の制御を適用し、ボタンやsliderから始まるgestureを画像操作として扱わない。
- 作品比較sliderの中間値でも、選択中エリアの映像または写真は不透明のまま表示する。
- 前面カメラはpreviewと撮影結果をともに鏡像にする。
- 写真の拡張子やMIME typeだけを理由に選択前の拒否を行わず、実際のdecode結果で成功・失敗を判定する。
- 完成PNGは通常の画像要素として表示し、長押しメニューを抑止しない。
- 共有先が文、ハッシュタグ、URLを受け取らない場合は、アプリの失敗と断定しない。

## 本実装で確認する項目

- 中央固定のエリア選択とslider iconが、説明なしで理解できるか。
- 小さいエリアや離れた複数形状を、輪郭画像なしでも認識できるか。
- 標準color inputがiPhone Safari・Chromeで気持ちを色として選ぶ用途に十分使いやすいか。著しく使いにくい場合は、後続changeで基本色のプリセットまたは専用pickerを検討する。
- Android Chromeでカメラ、写真decode、保存、共有、SAS asset取得、release継続性が成立するか。
