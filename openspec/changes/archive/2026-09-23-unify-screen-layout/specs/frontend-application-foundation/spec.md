## MODIFIED Requirements

### Requirement: モバイル向けの基本レイアウト
システムは、スマートフォンの縦向き表示を基準とし、動的ビューポートとセーフエリアを考慮した全画面のアプリケーションshellを提供しなければならない（SHALL）。タイトル、テンプレート選択、制作の各pageは、再利用可能なshellを用いて同じセーフエリアpadding、headerの操作位置、headerおよび本文の最大幅の基準を共有しなければならない（MUST）。これらの共通寸法はCSS custom propertiesとして一箇所で定義しなければならない（MUST）。

#### Scenario: 縦向きのスマートフォンで表示する
- **WHEN** ユーザーが縦向きのスマートフォン相当のビューポートでタイトル画面を開く
- **THEN** システムは主要な表示と操作をセーフエリア内に配置し、通常のページスクロールを発生させずに画面を表示する

#### Scenario: テンプレート選択または制作画面を表示する
- **WHEN** ユーザーがテンプレート選択画面または制作画面を表示する
- **THEN** システムはタイトル画面と同じ基準のセーフエリアpaddingおよびheader操作位置で画面を表示し、画面固有の本文だけを縦方向にスクロール可能にする

### Requirement: 共通headerの操作責務
システムは、画面横断で再利用する戻る操作を、見た目、アイコン、十分な操作領域、無効状態、click通知だけを担う汎用UI部品として提供しなければならない（SHALL）。この部品はroute遷移、制作sessionの生成・破棄、外部入出力を実行してはならない（MUST NOT）。利用するpageはclick通知を受け、遷移先と必要なsession操作を決定しなければならない（MUST）。言語切替操作はタイトル画面のheader右側だけに表示しなければならない（MUST）。

#### Scenario: テンプレート選択画面からタイトルへ戻る
- **WHEN** ユーザーがテンプレート選択画面の戻る操作を実行する
- **THEN** pageは開始状態をリセットしてからタイトル画面へ遷移し、戻るUI部品自体はsessionまたはrouterを操作しない

#### Scenario: 制作画面からテンプレート選択へ戻る
- **WHEN** ユーザーが制作画面の戻る操作を実行する
- **THEN** pageは制作sessionをテンプレート選択へ戻す既存の処理を実行してから遷移し、戻るUI部品自体はsessionまたはrouterを操作しない

#### Scenario: タイトル以外の画面を表示する
- **WHEN** ユーザーがテンプレート選択画面または制作画面を表示する
- **THEN** システムは言語切替操作をheaderに表示しない
